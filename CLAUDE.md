# Rules

- Never run remote git operations (push, pull, fetch, or anything that touches `origin`). The user does these themselves. Local commits are fine when asked.
- Tell questions apart from instructions. When the user asks "can it...?", "is it possible...?", "how do I...?" or "why...?", answer and explain (offer the change if useful) and do not edit files or run anything that changes state. Act only on explicit instructions such as "do X", "add X", "update X".
